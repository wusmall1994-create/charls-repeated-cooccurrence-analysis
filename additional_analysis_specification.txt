Analysis specification, 8 October 2026, before new model fitting

This is a post-primary-analysis extension, not an original preregistered protocol. Keep original primary comparisons and all existing sensitivity results. Do not choose analyses by statistical significance.
1. Describe complete vs incomplete baseline covariates among unique eligible participants at first eligible origin. Report available-case denominators, continuous means/SDs, categorical proportions and absolute standardized differences; report interval-level outcome observation and IADL progression descriptively without independence tests.
2. Chained equations impute missing baseline marital status, hukou, smoking, drinking, BMI, log income and individual other-disease items. Age, sex and education enter as observed predictors. Use 20 imputations, 20 initial iterations, PMM (5 donors) for continuous variables and logistic regression for binary items, multinomial regression for marital status if needed. Include wave-specific observed exposure, origin and destination indicators with eligibility/observation indicators and history category indicators. Do not impute exposures, outcomes or eligibility. Recompute disease count after item imputation. Refit observation weights and current and history outcome models per imputation; remove missingness indicators from imputed substantive models. Pool log RRs and clustered variances using Rubin rules. Inspect traces and logged events; extend iterations if needed.
3. Tabulate joint cumulative co-occurrence C and depressive-symptom D counts within each origin wave W (C <= D <= W). Within the existing complete-history, currently symptomatic IADL sample, fit logistic progression ~ C + factor(W,D) + original baseline adjustment. Estimate a one-wave increase in C holding D and W fixed only for observed starting cells with adjacent C+1 cells; require both cells >=20 intervals, >=5 events and >=5 non-events. Standardize over eligible observed starting intervals. Fix this support definition for 500 whole-participant bootstrap draws; refit observation weights and outcome models and resample the target. Report target size, excluded cells, risks and risk difference. This is an associational composition contrast, not RERI or a causal decomposition.
4. Lagged exposure sensitivity retains IADL-only functional origins, requires an observed exposure at the preceding wave, and contrasts preceding-wave co-occurrence with preceding-wave depressive symptoms only. Refit observation weights in this eligible subset, including preceding-wave exposure and original observation predictors. Outcome models use lagged exposure and original baseline covariates and interval, without adjusting current exposure. This changes the estimand and does not eliminate reverse causation.
5. Retain existing interval-specific cumulative estimates, interactions and original primary estimates. No observed-effect post hoc power calculation or between-disease ranking.

Computational amendment before inspecting expanded-imputation results: the sequential run was stopped because profiling showed approximately 19 seconds per chain-iteration. The same 20 imputations and 20 iterations are run as independent chains using seeds generated by set.seed(261008); chain seeds are recorded. Parallel worker count does not change these seeds. No model, predictor, inclusion rule or outcome contrast was changed.
